# `src/lib`

## Purpose

Own shadcn's native shared utility location.

## Owns

- `utils.ts`: `cn` class name merge helper generated by shadcn

## Structure

- `utils.ts`: shared UI utility used by shadcn components

## Use This Folder When

- Maintaining shadcn-generated utility code

## Do Not Put Here

- Feature-domain logic
- Database helpers
- Environment parsing

## Extend / Update Checklist

- Keep this folder aligned with `components.json`
- Prefer `shared/` for new app-owned reusable utilities
